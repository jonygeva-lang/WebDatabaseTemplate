How to play
Objective
The goal of FreeCell is to move all 52 cards into the four foundation piles (one for each suit), building each suit in ascending order from Ace to King.

Basic Rules
1. Moving Cards in the Tableau
  • You can move cards between columns.
  • Cards must be placed in descending order (King → Ace).
  • Cards must alternate colors (red on black, black on red).
  • Example: Valid: 8♠ → 7♥ → 6♣

2. Free Cells
  • You can move any single card into a free cell.
  • Each free cell can hold only one card.
  • Cards in free cells can be moved back to the tableau or to foundations.

3. Empty Columns
  • Any card can be moved into an empty column.
  • Empty columns are very powerful because they help you rearrange sequences.

4. Moving Multiple Cards
  • You can move sequences of cards only if you have enough free cells or empty columns.
  • The more empty spaces you have, the bigger sequences you can move.

5. Foundations
  • Build piles by suit from Ace → King.
  • Only Aces can be placed first.
  • Once a card is in a foundation pile, it usually stays there.

Winning the Game
You win when:
  • All cards are placed in the foundation piles
  • Each suit is complete from Ace to King
